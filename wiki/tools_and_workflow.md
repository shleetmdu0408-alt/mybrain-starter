# tools_and_workflow — この Vault で使える道具

> **「何ができるんだっけ」と思ったらここを開く。** スキル・コマンド・自動で動く仕組みの一覧。
> 詳しい使い方は `docs/` にある。ここは「いつ使うか」の一覧。

## 節索引

| 節 | 何が書いてあるか |
|---|---|
| 1. スラッシュコマンド | 自分で打つ命令の一覧 |
| 2. 自動で動く仕組み | 打たなくても動くもの（フック） |
| 3. 外部サービス連携（MCP） | PubMed・カレンダー・メールなど |
| 4. 1日・1週間の回し方 | いつ何をするか |

> 大きくなったら「節索引」の各行に `grep -n "^## 1\."` のような行番号の取り方を書き足す。
> そうすれば AI が該当する節だけを読める（全文を読まなくて済む）。

## 1. スラッシュコマンド（自分で打つ）

| コマンド | 何をするか | 使う場面 |
|---|---|---|
| `/paper <疑問>` | PubMed の一次文献から調べて `reports/` に残す | 臨床の疑問・文献調査・抄読会の準備 |
| `/daily [メモ]` | 今日のデイリーノートを作る・追記する | 思いついたことをその場で置く |
| `/sync` | 会話やデイリーの内容を wiki に構造化して反映 | 話が一区切りついたとき |
| `/weekly` | 週次レビュー（振り返り→反映→点検→来週の予定） | 週1回。日曜か月曜に固定する |
| `/inbox` | スマホから届いたメモを処理する | パソコンを開いたとき |
| `/raw` | `raw/` に置いた素材（論文 PDF 等）を wiki に構造化 | 資料を放り込んだあと |
| `/deliver <依頼>` | PDF/Word/Excel/PPT の成果物を作る | 人に渡すものを作るとき |
| `/nlm <資料>` | 重い読み込みを NotebookLM に外注 | 論文3本以上をまとめて読むとき |
| `/correct <指摘>` | 「こう直して」を恒久ルールとして記録 | AI の振る舞いを直したいとき |

## 2. 自動で動く仕組み（打たなくても動く）

| 仕組み | いつ | 何が起きるか |
|---|---|---|
| **inbox チェック** | Claude Code を開くたび | `inbox/` に未処理メモがあれば件数とファイル名を最初の返事で知らせる |
| **サイズチェック** | Claude Code を開くたび | `CLAUDE.md` や `rules/` が重くなっていたら知らせる。正常時は何も出さない |
| **朝のブリーフィング** | `おはよう` と打ったとき | 天気／1ヶ月以内の記念日／今日と今週の予定／進行中／未解決の問い／ニュース |
| **おやすみルーティン** | `おやすみ` と打ったとき | 今日あったことの一覧 → 取りこぼし → 「今日はどうでしたか？」。一言を答えると `daily/` の `## 日記` に整えて入る |

仕組みの中身は `.claude/hooks/` にある（シェルスクリプト。直接読める）。

## 3. 外部サービス連携（MCP）

MCP（Model Context Protocol）＝ AI に外部サービスを触らせる仕組み。**コマンドは不要。普通に日本語で頼めば使う。**

### 入れておくプラグイン（必須2つ）

| プラグイン | 何が入るか | 依存しているもの |
|---|---|---|
| **`bio-research`** | PubMed 検索・論文全文（PMC）・臨床試験（ClinicalTrials.gov）・論文横断検索 | `/paper` |
| **`anthropic-skills`** | PDF / Word / Excel / PowerPoint の生成 | `/deliver`・`/raw`（資料の読み取り） |

入れ方 → `docs/02_PubMedの使い方.md`「1. プラグインを入れる」。`/plugin` で一覧が開く。

### 使えるようになるもの

| サービス | できること | 頼み方の例 | 必要な設定 |
|---|---|---|---|
| **PubMed / 論文全文** | 論文の検索・書誌情報・全文取得・関連論文・ID 変換 | 「膝OAの運動療法の最新 RCT を探して」 | `bio-research`。**無くても同梱スクリプトで検索できる** |
| **臨床試験** | ClinicalTrials.gov の試験を検索 | 「この薬剤の進行中の第III相試験は？」 | `bio-research` |
| **論文横断検索** | 2億本超を横断。被引用数・雑誌の格付き | 「〇〇にエビデンスはある？」 | `bio-research` |
| **成果物の生成** | PDF / Word / Excel / PowerPoint を作る | 「比較表を Excel で出して」 | `anthropic-skills` |
| **Google カレンダー** | 予定の確認・作成・変更 | 「来週の予定は？」 | コネクタの接続（任意） |
| **Gmail** | メールの検索・下書き作成 | 「〇〇からのメール探して」 | コネクタの接続（任意） |
| **Google ドライブ** | ファイルの検索・読み取り | 「ドライブの〇〇を読んで」 | コネクタの接続（任意） |

> [!warning] 論文ツールには引用の義務がある
> PubMed のツールは**出典の明示と DOI の併記**、横断検索のツールは**番号付きの引用と文献リスト**が利用条件。
> このルールは `rules/corrections/medical.md` にも書いてある。

> [!important] 送信・削除・公開は勝手にやらない
> AI は下書きまで作るが、**送信・削除・購入は必ず確認を挟む**。

## 4. 1日・1週間の回し方

- **朝**：`おはよう` → 天気・予定・進行中を確認
- **日中**：思いついたことは `/daily` で置く。スマホからは `inbox/` に書く
- **調べもの**：臨床・研究なら `/paper`、それ以外は普通に聞く → 答えは `reports/` に残る
- **夜**：`おやすみ` → 今日あったことを見て、一言だけ日記を書く
- **週1回**：`/weekly` → 反映・点検・来週の Next Action
