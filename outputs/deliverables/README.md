# outputs/deliverables — 人に渡す成果物

`/deliver` で作った PDF / Word / Excel / PowerPoint がここに入ります。

- ファイル名：`YYYY-MM-DD_主題.拡張子`（日付は作成日）
- 古くなって作り直したものは `archive/` に移す（消さない）
- HTML から PDF を作った場合、ソースは `src/` に残す

> 🔧 Vault の外（例：共有フォルダ）に出したい場合は、
> `.claude/skills/deliverable/SKILL.md` の保存先を書き換え、
> `.claude/settings.json` の `permissions.additionalDirectories` にそのフォルダを追加してください。
