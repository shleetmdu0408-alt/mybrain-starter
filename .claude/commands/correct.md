description: 修正指示を rules/corrections/ に恒久ルールとして記録する
argument-hint: <こう直してほしい、という内容>
allowed-tools: Read, Edit, Bash(date:*)
---

オーナーからの修正指示を恒久ルール化する。

指示内容: $ARGUMENTS

手順:
1. `date +%Y-%m-%d` で今日の日付を確認する
2. `rules/corrections.md`（ルーティング表）で**どのカテゴリのファイルに書くか**を決め、その1ファイルだけを読む
3. 該当カテゴリの**先頭**に3行で追記する:
   ```
   ## YYYY-MM-DD
   - 指摘：（オーナーが何を直してほしいと言ったか。具体的に）
   - 今後：（次から自分がどう動くか。具体的な「する/しない」で）
   ```
4. 既存の指示と矛盾する場合は、古い行に `（YYYY-MM-DD 更新）` を付けて最新を優先する
5. 「丁寧に」のような抽象表現にしない。検証可能な行動で書く
6. ファイルが 5,000 バイトを超えていたら、卒業ルール（`rules/corrections.md` 末尾）に従って移設・統合の候補を提示する

すでに実際に**失敗した**ことへの指摘なら、`rules/mistakes/<該当カテゴリ>.md` にも「やらかし / 原因 / 再発防止」の3行で追記する。
