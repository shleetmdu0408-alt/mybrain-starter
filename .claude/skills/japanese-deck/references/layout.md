生成前に読む。ここに書いてあるのは、**毎回同じ場所で事故る**ことばかり。

| 項目 | 値 |
|---|---|
| スライド | 13.333 × 7.5 インチ |
| 左右マージン | 0.75（本文幅 11.833） |
| 見出し | y=0.52、高さ1.05、26pt太字、行間1.18 |
| サブ見出し | y=1.62、13pt、ミュート色 |
| 本文の開始 | y=2.1〜2.4 |

| カード間の間隔 | 0.26（3枚並べるなら幅3.72、ピッチ3.98） |

日本語は1文字＝1em（全角）なので、幅の見積もりは `文字数 × フォントpt ÷ 72` インチで足りる。**14文字を3インチに収めたければ15pt以下**。

## 日本語固有の落とし穴

### フォント

**`Yu Gothic` を指定する。** Windows 8.1以降と Mac 版 Office の両方に入っている。python-pptx で `run.font.name` を設定しても**ラテン字形しか変わらない**ので、`a:latin` `a:ea` `a:cs` の3つに同じ typeface を書き込む必要がある（`deck_lib.py` の `_typeface()` がこれをやる）。

避けるもの:
- **`Aptos`**（Office 2023以降の既定）— 古い環境に無く、代替フォントの幅も違う
- **Mac専用フォント**（`Hiragino Kaku Gothic ProN` 等）— Windows で置換される
- 明朝とゴシックの混在 — 日本語では字面の差が大きく、統一感が壊れる

### 絵文字を使わない

`✅` `❌` `⚠️` は環境によって**カラー絵文字**に化け、モノクロのデザインの中で浮く。フォントによっては豆腐になる。

代わりに **JIS X 0208 にある記号**を使う。日本語フォントなら確実にある。

```
◯ ○ △ × ★ ☆ ※ → ← ↑ ↓ ⇒ ・ ─ ｜
```

`✓`（U+2713）は JIS X 0213 にあり、多くの日本語フォントで出るが、確実性を取るなら `◯` にする。

### 禁則と折り返し

python-pptx は折り返しを PowerPoint に任せるので禁則処理は効くが、**明示的な `\n` を入れた行が想定より手前で折り返すと、句点だけが次行に残る**（「〜と言うか。」の「。」だけが2行目）。

対策: 改行を自前で入れず、**枠を少し広げて自動折り返しに任せる**。どうしても改行位置を制御したいなら、その行が確実に収まる幅を計算してから入れる。

### 数字とラテン文字

日本語の中の半角英数は、日本語フォントのラテン字形で描かれる。`Yu Gothic` のラテン字形は素直なので問題ないが、**大きな数字（40pt以上のスタットカード）は字間が空いて見える**。気になるなら数字だけ `charSpacing` を詰める（`letterSpacing` ではない）。

## 色の作り方

**内容から色を決める。** 別のプレゼンに差し替えても成立する配色なら、選び方が甘い。

支配色を1つ（視覚的な重みの6〜7割）、補助を1〜2、アクセントを1。全部を同じ重みにしない。

意味と色を結びつけると、そのまま通しのモチーフになる。前回の例:

| 役割 | 色 | 意味 |
|---|---|---|
| 地（ダーク） | `0F2C3A` 濃紺墨 | 表紙・結論・最終ページ |
| 地（ライト） | `FFFFFF` / カード `F0F4F6` | 本編 |
| 本文 | `182228` / ミュート `5E727B` | |
| 緑 `146E4C` | 解けた・開いた | 良い状態 |
| 赤 `A03328` | 閉じた・壊れた | 悪い状態 |
| 黄 `A8710F` | 要検証 | 裏が取れていない |

**ダーク地に濃い色を置かない。** 上の緑・赤・黄はライト地用。ダーク地では明るい版に差し替える（`5FC79B` / `E88B7E` / `E3AE4A`）。ここは毎回やらかす。

## やらないこと

- **タイトル下のアクセント線** — AI製スライドの典型。余白か地色で区切る
- **装飾用の色帯・サイドストライプ・カードの片側だけの縁** — 情報を持たない。カードを区切りたいなら地色の濃淡か影
- **本文の中央揃え** — 中央揃えは見出しだけ。段落と箇条書きは左揃え
- **全スライド同じレイアウト** — 2カラム、カード3枚、2×2、表、スタットカードを混ぜる
- **文字だけのスライド** — 表・カード・数字・図形のどれかを必ず入れる
- **クリーム／ベージュの地色** — 指定が無ければ白かダーク

## よくある不具合と原因

| 症状 | 原因 |
|---|---|
| 脚注にページ番号が重なる | 脚注の幅を本文幅いっぱいに取っている。−0.95 する |
| 脚注が表に食い込む | 表の高さ＝行高×行数。表の `y + 行高×行数` を計算して脚注を置く |
| カードの下半分が空く | 項目数がカードの高さに足りていない。高さを詰めるか項目を足す |
| 下だけ1.5インチ空く | 本文の開始位置が高すぎる。y を 0.2〜0.4 下げる |
| 図形が消える | 座標がスライド外。python-pptx は**クランプせずそのまま書く** |
| 太字が効かない | ラテン字形にだけフォントを設定している（`a:ea` を忘れている） |
