# inbox — スマホから投げる場所

> **このファイルは消さない・移動しない。** 使い方の説明です。

## 何のためのフォルダか

スマホでは Claude Code を使えません。外出先で思いついたことは、
**スマホの Obsidian でこのフォルダに .md を1枚作って書く**だけにしておき、
次にパソコンを開いたときに `/inbox` で処理します。

## 使い方

1. スマホの Obsidian で `inbox/` に新規ノートを作る（ファイル名は何でもよい）
2. 思いついたことを雑に書く。**書式は崩れていてよい**
3. パソコンで Claude Code を開くと、**未処理の件数が最初の返事で知らされる**
4. `/inbox` と打つと、1件ずつ行き先を決めて処理し、原文を `inbox/done/YYYY-MM/` へ移す

## 大事なこと

- **AI はこのフォルダに書き込めない**（`.claude/settings.json` で禁止している）。
  スマホ側とパソコン側が同時に同じファイルを触ると、クラウド同期が「競合コピー」を作って壊れるため。
- 処理が済むまで消さない。原文は `done/` に残す。

## スマホ側の準備（任意）

- Obsidian（iOS/Android）を入れ、この Vault フォルダをクラウド同期（Google ドライブ / iCloud / Dropbox）で共有する
- Android なら DriveSync、iOS なら iCloud Drive に Vault を置くのが簡単
