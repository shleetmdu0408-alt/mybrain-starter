# raw — 素材置き場（読み取り専用）

このフォルダには、**手を加えていない素材そのもの**を置きます。

- 論文 PDF、スライド、Excel、Web ページの保存、写真、講演の資料 …

## ルール

- **AI はこのフォルダに書き込めない**（`.claude/settings.json` で `Write` / `Edit` を禁止しています）。
  削除・改名・上書きもしません。素材は「証拠」なので、原本のまま残します。
- 素材を入れたら `/raw` と打つと、AI がまず「**何のために入れましたか？**」と聞きます。
  - ①wiki に構造化 ②要点だけ知りたい ③調べものの出発点 ④保管だけ
  - 同じ素材でも、目的によってやることが変わるので、ここを飛ばしません。
- 処理の記録は `wiki/raw_inventory.md` に残ります。

## 患者情報について

**患者の個人情報を含むファイルをここに置かないでください。**
匿名化していない画像・書類は、Vault の外で管理してください。
