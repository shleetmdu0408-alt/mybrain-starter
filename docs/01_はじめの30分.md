# はじめの30分 — 最初のセッションでやること

[SETUP.md](../SETUP.md) が終わっている前提です。**上から順に、AI と会話しながら進めてください。**

---

## この Vault の考え方（2分で読める）

普通のメモアプリと違うのは、**AI が構造を保つ役をする**ところです。

- あなたは思いついたことを雑に投げる
- AI が「これはどのページに書くべきか」を判断して、正しい場所に置く
- **同じ事実は1箇所にしか書かない。** 他のページからはリンクだけ張る
- だから、1年後も2年後も「どこに書いたっけ」にならない

そのために、AI は毎回 `CLAUDE.md`（この Vault の憲法）を読んでから動きます。
**振る舞いを変えたければ、AI に言うのではなく `CLAUDE.md` と `rules/` を書き換えます。**

---

## ステップ1：自分のことを覚えさせる（10分）

```
Memory.md を私の情報に書き換えたい。順番に質問してください
```

AI が聞いてくるので答えていくだけです。**書くのは「1年で変わらない事実」だけ。**

- 名前・職種・専門・所属の種類
- 家族構成（必要なら）
- 研究テーマ・取りたい資格
- **AI にどう振る舞ってほしいか**（ここが一番大事）

> 金額・日程・進捗は `Memory.md` に書きません。それらは `wiki/` か `Home.md` に置きます。

## ステップ2：架空の記入例を消す（5分）

```
記入例として入っているファイルを一覧して。私に不要なものを消してください
```

消してよいもの：

- `wiki/research_example.md` / `wiki/clinical_knee_oa.md`（自分の分野のページに置き換える）
- `reports/2026-01-15-調査-…md`（形式を見たら消してよい）
- `daily/2026-01-15.md`
- `Home.md` と `wiki/open_questions.md` の中身

**消さないほうがよいもの：** `rules/` 配下、`templates/`、`wiki/index.md`、`wiki/life_events.md`、`wiki/tools_and_workflow.md`

## ステップ3：いま抱えているものを1つ入れてみる（10分）

いちばん実感が湧くのは、**今まさに困っていること**を入れることです。

```
/paper <いま気になっている臨床の疑問>
```

または

```
/daily 今日やること：〇〇の締切が来週。△△を調べる
```

そのあと：

```
/sync
```

と打つと、いま話した内容が `wiki/` の正しいページに構造化されて入ります。
**「調べて終わり」にならないのがこの Vault の要点です。**

## ステップ4：気になった振る舞いを直す（5分）

AI の答え方で気になるところがあったら、その場で：

```
/correct 表を使いすぎ。箇条書きで答えてほしい
```

これで `rules/corrections/` にルールとして残り、**次から自動で守られます**。
同じことを二度言わなくてよくなるのが、このテンプレートの一番の効きどころです。

## 最初の1週間の目安

| 日 | やること |
|---|---|
| 1日目 | 上の4ステップ |
| 2〜6日目 | 朝は `おはよう`、夜は `おやすみ`。気になったら `/paper` や `/daily` |
| 7日目 | `/weekly` を回す。**ここで初めて Vault が「育つ」感じが分かります** |

---

## 困ったら AI に聞く

このテンプレートの仕組みは、**全部ただのテキストファイル**です。AI が自分で読めます。

```
なぜ「おはよう」で天気が出るのか、仕組みを説明して
```
```
/weekly は具体的に何をするのか、スキルのファイルを読んで教えて
```

分からないことは、まず AI に聞いてください。
