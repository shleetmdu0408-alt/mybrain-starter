# 日々の回し方 — 1日・1週間のサイクル

**続けるコツは「打つものを減らすこと」です。** 覚えるのは `おはよう` / `おやすみ` / `/weekly` の3つで十分です。

---

## 1日のサイクル

### 朝：`おはよう`

天気・1ヶ月以内の記念日・今日と今週の予定・進行中の案件・未解決の問い・ニュースが1画面で出ます。

- 予定は Google カレンダーを繋いでいれば出ます（繋いでいなければ黙って飛ばします）
- 記念日は `wiki/life_events.md` の表から読んでいます

### 日中：思いついたら投げる

| 場面 | やること |
|---|---|
| メモしたい | `/daily <内容>` |
| 臨床・研究の疑問 | `/paper <疑問>` |
| 資料を読ませたい | `raw/` に入れて `/raw` |
| 人に渡すものを作りたい | `/deliver <依頼>` |
| AI の振る舞いを直したい | `/correct <指摘>` |
| **外出先で思いついた** | スマホの Obsidian で `inbox/` に書く → 次にパソコンで `/inbox` |

### 夜：`おやすみ`

1. **今日あったこと**（予定の実績・今日動いたファイル）を一覧で出す
2. **取りこぼし**（未処理の inbox、wiki に反映していない調べもの、期限切れ）を教える
3. **「今日はどうでしたか？」**と一言だけ聞く

一言を答えると、`daily/` の `## 日記` に整えて入ります。
**書くのはあなた。AI は感想を足しません**（「充実した1日でしたね」と勝手に書かない）。

書きたくない日は「今日はいい」でスキップして構いません。催促しません。

---

## 週1回：`/weekly`

**これを回すかどうかで、Vault が育つか散らかるかが決まります。**

やっていること：

1. 過去7日のデイリーノートから決定事項（`DECISION:`）と新しい事実を拾う
2. それを `wiki/` の正本ページに反映する
3. **点検（lint）** — リンク切れ・重複・矛盾・古い情報を機械的に洗い出す
4. 来週の Next Action を3〜5件提案する
5. `reports/YYYY-MM-DD-週次レビュー.md` に記録を残す

所要は10〜20分。**曜日を固定してください**（日曜の夜が続けやすい）。

> 点検で見つかった問題は `wiki/lint-issues.md` に溜まります。
> **AI は勝手に直しません。** 直すかどうかはあなたが決めます。

---

## 情報の流れ（どこに何が残るか）

```
思いつき ──→ daily/            （その日の記録。あとで拾われる）
                 │
                 ├─ /sync ──→ wiki/         （知識の正本。1トピック1ページ）
                 │              ↑
調べもの ──→ reports/ ──────────┘（経緯・出典・検索式。結論は wiki へ）
                 
素材 ────→ raw/ ──→ /raw ──→ wiki/         （読み取り専用。原本は残す）

スマホ ──→ inbox/ ──→ /inbox ──→ 上のどれか
```

**覚えるのは1つだけ：** 答えは必ずファイルに残る。チャットに流して消えることはない。

---

## 続かなくなったときは

- **`/weekly` を2週飛ばしたら、それは「重すぎる」というサイン。** AI に「週次レビューを軽くしたい」と言えば手順を削ってくれます
- **使わないコマンドは消してよい。** `.claude/commands/` からファイルを消すだけです
- **`おはよう` が長すぎるなら**、`.claude/hooks/morning-brief.sh` の中の「ニュース」節を削れば短くなります（AI に頼めばやってくれます）
