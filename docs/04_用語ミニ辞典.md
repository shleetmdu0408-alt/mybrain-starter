# 用語ミニ辞典 — 出てくる IT 用語

プログラミングをやったことがなくても使えるように作っていますが、
説明の中でどうしても出てくる言葉をまとめました。**分からなくなったらここに戻ってください。**

---

## この Vault まわり

| 用語 | 一言でいうと |
|---|---|
| **Vault（ボールト）** | ノートを入れておくフォルダ全体のこと。Obsidian の言い方 |
| **Obsidian** | Markdown のノートアプリ。フォルダの中の .md ファイルをそのまま読み書きする |
| **Markdown（.md）** | 見出しや強調を記号で書くテキスト形式。`# 見出し` `**太字**` など |
| **frontmatter** | ノートの先頭にある `---` で囲まれた部分。日付や種類などの情報を機械が読める形で置く場所 |
| **`[[wikilink]]`** | ノート同士のリンク。Obsidian ではクリックで飛べる |
| **正本（せいほん）** | 「この事実はこのページに書く」と決めた1つのページ。同じ事実を2箇所に書かないための考え方 |
| **MOC** | Map of Content。テーマごとの地図ページ。リンクだけを集める |

## Claude Code まわり

| 用語 | 一言でいうと |
|---|---|
| **Claude Code** | Anthropic 社の AI「Claude」を、パソコンのフォルダを触らせながら使う道具 |
| **CLAUDE.md** | AI が毎回必ず読むルールファイル。ここを書き換えると AI の振る舞いが変わる |
| **スキル** | AI に「この作業はこの手順でやれ」と教える手順書。`.claude/skills/` にある |
| **スラッシュコマンド** | `/paper` のように `/` で始める命令。`.claude/commands/` にある |
| **フック（hook）** | 決まったタイミングで自動で走る小さなプログラム。「おはよう」で天気が出るのはこれ |
| **MCP** | AI に外部サービス（PubMed・カレンダー・メール）を触らせるための共通規格 |
| **コネクタ / プラグイン** | MCP を使って外部サービスと繋ぐ部品。Claude Code の設定から追加する |
| **トークン** | AI が読み書きする文章の量の単位。**読ませる量が多いほど遅く・高くなる**ので、この Vault は「必要なページだけ読む」設計にしてある |
| **コンテキスト** | AI が一度に覚えていられる範囲。ここが尽きると話の前半を忘れる |

## 論文検索まわり

| 用語 | 一言でいうと |
|---|---|
| **PubMed** | 米国立医学図書館の医学文献データベース |
| **PMID** | PubMed が論文1本ずつに振る番号。引用の身分証明書 |
| **DOI** | 論文に世界共通で振られる ID。`10.1001/jama.2021.0411` のような形 |
| **PMC** | PubMed Central。全文が無料で読める論文の置き場 |
| **MeSH** | PubMed の統制語彙。表記ゆれを吸収してくれる検索用の共通語 |
| **E-utilities** | PubMed の公式 API（プログラムから使う入口）。登録も鍵も不要 |
| **API** | プログラムが別のサービスを呼び出すための窓口 |

## パソコン操作まわり

| 用語 | 一言でいうと |
|---|---|
| **ターミナル** | 文字でパソコンに命令する黒い画面（Mac なら「ターミナル.app」） |
| **シェルスクリプト（.sh）** | ターミナルの命令をまとめて書いたファイル。フックの中身はこれ |
| **`bash xxx.sh`** | そのスクリプトを実行する命令 |
| **パス** | ファイルの住所。`~/Documents/MyBrain` の `~` は自分のホームフォルダ |
| **git** | ファイルの変更履歴を管理する道具 |
| **GitHub** | git の置き場を提供するサービス。このテンプレートもここで配っている |
| **リポジトリ** | GitHub 上の1つのプロジェクト置き場。**public は全世界に公開、private は自分だけ** |
| **clone（クローン）** | GitHub の中身を自分のパソコンにコピーすること |
| **push（プッシュ）** | 自分のパソコンの中身を GitHub に送ること。**public に push = 世界に公開** |
