# カスタマイズ — 自分用に書き換える場所

**優先度順**に並べています。上の3つだけやれば実用になります。

---

## ★★★ 必ず書き換える

| ファイル | 何を直すか |
|---|---|
| `Memory.md` | **全部**。名前・職種・専門・家族・AI への要望。架空の記入例が入っています |
| `CLAUDE.md`「オーナー」節 | `<氏名>` `<職種>` `<プログラミング経験>` の3箇所 |
| `.claude/hooks/morning-brief.sh` の 20行目あたり | `LAT` / `LON` / `PLACE` — 天気を出す地点（既定は東京駅）。緯度経度は Google マップで地点を右クリックすると出ます |

## ★★ 早めに書き換える

| ファイル | 何を直すか |
|---|---|
| `wiki/life_events.md` | 誕生日・記念日の表。**朝のブリーフィングがこの表を読みます**（書式を崩さないこと） |
| `Home.md` | 「進行中」の表を自分の案件に。記入例は消す |
| `wiki/index.md` | 記入例のページを消し、自分の分野のページを足す |
| `wiki/open_questions.md` | 自分がいま答えを出せていない問いに置き換える |
| `CLAUDE.md`「読み込みルール」の表 | 自分の分野に合わせる（`wiki/research_*` `wiki/clinical_*` など） |

## ★ 使いながら育てる

| ファイル | いつ直すか |
|---|---|
| `rules/corrections/*.md` | AI の答え方を直したいとき（`/correct` で自動追記される） |
| `rules/mistakes/*.md` | AI が実際に失敗したとき |
| `rules/design/*.md` | 成果物の見た目に注文があるとき（形式ごとに分かれている） |
| `rules/naming.md` | ファイル名や frontmatter の語彙を変えたいとき |

---

## 消してよいもの（記入例）

```
wiki/research_example.md
wiki/clinical_knee_oa.md
reports/2026-01-15-調査-変形性膝関節症に対する運動療法のエビデンス.md
daily/2026-01-15.md
```

AI に「記入例のファイルを消して」と頼めばまとめてやってくれます。

> 消すまでの間、`/weekly` の点検で「90日以上 `date:` が動いていないページ」として記入例が並びます。
> **異常ではありません**（記入例の日付が固定してあるため）。自分のページに置き換えれば消えます。

## 消さないほうがよいもの

- `rules/` 配下（**AI の振る舞いの土台**）
- `templates/`（ノートのひな形）
- `wiki/index.md` `wiki/lint-issues.md` `wiki/open_questions.md` `wiki/raw_inventory.md`（運用ページ）
- `.claude/` 配下（仕組み本体）

---

## 機能を減らしたいとき

| 消したい機能 | やること |
|---|---|
| 朝のブリーフィングのニュース | `.claude/hooks/morning-brief.sh` の「6. ニュース」節を削る |
| 朝・夜の自動起動そのもの | `.claude/settings.json` の `UserPromptSubmit` を削る |
| 使わないコマンド | `.claude/commands/` から該当ファイルを消す |
| NotebookLM 連携 | `.claude/skills/notebooklm/` と `.claude/commands/nlm.md` を消す |

**どれも AI に頼めばやってくれます。**「朝のニュースはいらない」と言えば十分です。

---

## 機能を足したいとき

新しいスキルを作りたくなったら：

```
/skill-creator
```

または AI に直接頼んでください。

```
学会発表の準備を手伝うスキルを作りたい。手順を一緒に考えて .claude/skills/ に作って
```

> ただし **足す前に「既存のスキルで足りないか」を確認**してください。
> スキルが増えるほど AI が読む量が増え、判断が鈍ります（`CLAUDE.md` の設計方針）。

## Windows で使う場合

このテンプレートは Mac で作られています。次の箇所は書き換えが要ります。

| 場所 | 問題 | 対処 |
|---|---|---|
| `.claude/skills/weekly-review/SKILL.md` の `date -v-7d` | macOS 専用の書き方 | `date -d "7 days ago"` に変える |
| `.claude/hooks/lint-scan.sh` の `date -j -f` | 同上 | 同上 |
| `rules/design/pdf.md` の Chrome のパス | Mac のパス | Windows の Chrome のパスに変える |

**AI に「Windows で動くように直して」と頼めば全部やってくれます。**
