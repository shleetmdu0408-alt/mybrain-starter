# lint.md — 週次ヘルスチェック

> Vault は足すだけだと、矛盾・重複・古い情報が溜まります。週に一度この手順で点検します。
> **「`wiki/` 全体を読む」方式は使いません。** wiki が育つと1セッションに収まらなくなるためです。
> この手順なら、wiki が何ページになっても読む量は合計 20KB 前後に収まります。

## いつやるか

- 週に1回（`/weekly` の Step 4）。または `raw/` を大量に投入した直後。

## 手順（この順に4段。上の段で出たものが下の段の入力になる）

### 第1段 — 機械点検（wiki を1文字も読まない）

```bash
./.claude/hooks/lint-scan.sh
```

全 md を走査して、読まなくても分かるものだけを数十行で出します。

| 出るもの | どの観点か |
|---|---|
| 行き先の無い `[[リンク]]` | **欠落**（2ページ以上から張られていれば、作るべきページ） |
| どこからもリンクされていない wiki ページ | 孤立 |
| `type:`／`status:` が [[naming]] の語彙表の外 | grep で引けなくなる |
| 同じ見出しが1ページに2つ | `[[ページ#節]]` が効かなくなる |
| `wiki/index.md` から辿れないページ | 目次の取りこぼし |
| 90日以上 `date:` が動いていないページ | **古い情報**の候補（一覧を出すだけ。古い＝悪いではない） |
| `wiki/` に残る未完了 TODO | 決着していないもの |
| **前回の lint からの差分** | 第3段の入力（下） |

### 第2段 — 重複・新規候補（各ページの**冒頭12行だけ**読む）

`wiki/index.md` と、全 wiki ページの冒頭12行だけを読む。

```bash
for f in wiki/*.md; do echo "--- $f"; head -12 "$f"; done
```

- **重複** — 似た主題のページが複数ないか。本文ではなく冒頭の要約ブロックで判定できる
- **新規候補** — 既存ページから派生して1ページ立てる価値のあるテーマはないか

### 第3段 — 前回の lint からの差分を読む（ページを読むのではない）

第1段のスクリプトが最後に**差分そのもの**を出します。読むのはそれだけ。
**消えた行（`-`）を特に見る** — 古い情報が残っているのではなく、新しい情報で上書きされた側に矛盾の種があります。

> [!warning] `date:` で絞る方式は使わない
> 「`date:` が過去7日のページ」で絞る案は、活動が多い週だと wiki の大半が該当して全読みと変わらなくなる。
> 原因は Vault が git 管理外で**比較対象が無い**こと。
> そこで lint 専用に前回の写し（`.claude/state/lint-snapshot`）を持たせ、差分を出すようにしてある。
> 副産物として、**`date:` の上げ忘れがここには影響しない**。

lint が終わったら**必ず基準を更新する**（忘れると次回の差分が2週間分になる。壊れはしない）。

```bash
./.claude/hooks/lint-scan.sh --snapshot
```

### 第4段 — 矛盾の当たり判定（grep だけ。全読みしない）

第3段の差分に出てきた**数値・金額・日付・固有名詞**を `wiki/` 全体に `grep` し、
古い側が別のページに残っていないか見る。**これが全読みなしで「矛盾」を拾う仕掛け**です。

```bash
grep -rn "8,000円\|第29回\|2027年3月" wiki/    # 例：学会費や日程を書き換えた週
```

## 出力（`wiki/lint-issues.md`）

`## 未対応` の下に観点別（矛盾／欠落／重複／古い情報／新規候補）で列挙する。**件数は書かない**（すぐ古くなる）。
対応が済んだものは `wiki/lint-issues.md` の `## 対応済み` へ1行で移す（本体は「今なにが残っているか」だけを見る場所にする）。

## 大事なこと

- **自動で勝手に消さない。洗い出して提案し、修正はオーナーの承認後**。
- 機械点検に出たものが全部おかしいわけではない。**孤立と古い `date:` は一覧を出すだけ**。
- 優先度の高い3件をオーナーに提示し、そこから片付ける。
- 全読みは復活させない。どうしても本文を確かめたいページが出たら、**そのページだけ**指名して読む。
