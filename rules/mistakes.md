# mistakes — やらかしの入口（ルーティング表）

> 実際にやってしまった失敗と、二度と繰り返さないためのトリガー付きルール。
> **このファイル自体に記録を書かない。** 中身は `rules/mistakes/` にカテゴリ別で置き、ここは**どれを読むかを決めるだけ**。
> 先回りの指示は `rules/corrections.md`（**同じ件を両方に書かない**。事件の詳細はこちら、今後の行動指針は corrections）。

## これから何をするか → 読むファイル（1つだけ）

| これから何をするか | 読むファイル |
|---|---|
| 金額・数値・体験談など事実を書く | `rules/mistakes/facts.md` |
| オーナーに実行してもらう手順書を書く | `rules/mistakes/procedures.md` |
| 案件の状態を書く／Next Action を出す | `rules/mistakes/status.md` |
| 「ルールを確認して」と聞かれた | `rules/mistakes/` 配下すべて |

## 書き方と運用（AI向け）

該当カテゴリのファイルの**先頭**に3行で追記する。

```
## YYYY-MM-DD
- やらかし：（何をして、何が問題だったか）
- 原因：（なぜそうなったか。一言で）
- 再発防止：（次から何を確認/実行するか。具体的なトリガー付きで）
```

- 同じミスを2回指摘されたら必ず記録（1回でも重大なら記録）。「気をつける」で終わらせず、**いつ・何を確認するか**まで書く
- 該当カテゴリが無ければ新しいファイルを作り、**この表に1行足す**

## 卒業ルール

`rules/corrections.md` 末尾と同じ（移設 → 昇格 → 統合 → 3ヶ月再発なしで archive）。**1ファイル 5,000 バイト以内。**
