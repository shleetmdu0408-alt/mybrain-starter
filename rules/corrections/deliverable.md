# 修正指示：成果物・長文

> **読むタイミング**：PDF/Word/Excel/PPT を作る前、長文を書く前。
> ここには**形式に依存しない指摘だけ**を書く。見た目・文字サイズ・作り込みの指摘は `rules/design/<形式>.md` へ。
> 入口は `rules/corrections.md`（ルーティング表）。

## 初期ルール（この Vault の出発点）

- 指摘：**`.md` で渡されても読みにくい。** 人に渡すものはドキュメント形式にしてほしい。
- 今後：最終成果物は `outputs/deliverables/YYYY-MM-DD_主題.拡張子` に、PDF / docx / xlsx / pptx のいずれかで保存する。
  形式が指定されていなければ、内容から判断して**作る前に一言で確認**する。

- 指摘：**「作成しました」と言われたのにファイルが無かった。**
- 今後：生成後に `ls -la outputs/deliverables/` で**実在を確認してから**完了報告する。推測で完了と言わない。

- 指摘：**配布物に制作の経緯を書かない。**（`NEW` バッジ、「〇〇から変更しました」等）
- 今後：受け取る人に関係のない差分・変更履歴は成果物に入れない。変更履歴は `reports/` の .md 側に書く。
