# MyBrain Starter — Claude Code で動く「第二の脳」の骨組み

医療者向けに作った **Obsidian Vault ＋ Claude Code** のテンプレートです。
日々のメモ・調べもの・論文検索・資料作成を1つのフォルダにまとめ、**AI が構造を保ったまま育てていく**ことを目指しています。

> このリポジトリには**個人情報は入っていません。** 中身のノートはすべて架空の記入例です。
> 実際に動く「仕組み」（ルール・スキル・自動化）だけが入っています。

---

## これで何ができるか

| 打つもの | 起きること |
|---|---|
| `おはよう` | 天気・今日の予定・1ヶ月以内の記念日・進行中の案件・未解決の問い・ニュースをまとめて出す |
| `/paper 膝OAに運動療法は有効？` | **PubMed の一次文献を検索**し、PMID・DOI・研究デザイン付きで整理して `reports/` に保存 |
| `/daily 明日 抄録の締切` | 今日のノートに振り分けて追記 |
| `/sync` | 会話で出た情報を wiki の正本ページに構造化して反映 |
| `/weekly` | 週次レビュー（振り返り → 反映 → 矛盾の点検 → 来週の予定） |
| `/deliver 比較表を Excel で` | PDF / Word / Excel / PowerPoint の成果物を作る |
| `おやすみ` | 今日あったことの一覧を出し、一言だけ聞いて日記に整えて残す |

**「調べて終わり」にならないのが要点です。** 答えは必ずファイルに残り、次に同じことを聞かれたら Vault から答えます。

## 何が入っているか

```
CLAUDE.md          ← AI が毎回読む「この Vault の憲法」。ここを書き換えると振る舞いが変わる
Memory.md          ← 1年で変わらない自分の事実（架空の記入例つき）
Home.md            ← 人が最初に開く入口。進行中の案件はここが正本
wiki/              ← 知識の正本ページ。1トピック1ページ
reports/           ← 調べものの答え（検索式・出典つき）
daily/             ← 日々のノート
inbox/             ← スマホから投げたメモの受け口
raw/               ← 論文 PDF などの素材（読み取り専用）
rules/             ← 命名規則・修正指示・失敗の記録・成果物のデザインルール
templates/         ← ノートのひな形
.claude/skills/    ← AI の作業手順（スキル）
.claude/commands/  ← スラッシュコマンド
.claude/hooks/     ← 自動で動く仕組み（朝・夜・起動時）
docs/              ← 使い方の説明（← まずここを読む）
```

## 設計の考え方（なぜこうなっているか）

- **同じ事実を2箇所に書かない。** 1トピック1正本。他からはリンクだけ張る
- **AI に全部読ませない。** 目次と1行要約を置き、必要なページだけ開かせる。だから何年使っても重くならない
- **修正を資産化する。** 「こう直して」と言ったことは `rules/` に残り、次から自動で守られる
- **AI に状態を判断させない。** 「停滞中」のような評価語を書かせない。記録が無いことは、やっていない証拠にならない
- **医学的な主張には一次文献を要求する。** PMID と DOI を必ず併記させる
